## Система заказов продуктов
Проект представляет собой распределенную систему для обработки заказов продуктов, состоящую из трех микросервисов, взаимодействующих через gRPC.

#### Архитектура
Система состоит из следующих сервисов:

OrderService - Сервис заказов
- Управляет жизненным циклом заказа
- Координирует взаимодействие между Inventory и Payment сервисами
- Отвечает за создание, оплату и отмену заказов

InventoryService - Сервис инвентаря
- Управляет наличием товаров на складе
- Обрабатывает резервирование и освобождение товаров
- Отслеживает остатки продуктов

PaymentService - Сервис платежей
- Обрабатывает финансовые транзакции
- Управляет процессом оплаты заказов
- Обрабатывает возвраты средств при отмене заказов
